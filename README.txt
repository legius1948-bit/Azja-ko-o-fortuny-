KOŁO FORTUNY AZJA — publikacja na GitHub Pages

Pliki w tym folderze:
- index.html — aplikacja
- manifest.webmanifest — ustawienia instalacji na ekranie początkowym
- sw.js — pamięć podręczna/offline
- icon-192.png i icon-512.png — ikony aplikacji

Publikacja:
1. Otwórz swoje repozytorium na GitHubie.
2. Dodaj wszystkie pliki z tego folderu do katalogu głównego repozytorium (obok innych plików; index.html musi być w katalogu głównym).
3. Zapisz zmiany przez Commit changes.
4. Wejdź w Settings → Pages.
5. Source: Deploy from a branch; Branch: main; Folder: /(root); kliknij Save.
6. Otwórz adres strony pokazany w sekcji GitHub Pages.

Dodanie na iPhone:
Safari → otwórz opublikowany adres → Udostępnij → Dodaj do ekranu początkowego → Dodaj.

Uwaga: lista obejmuje reprezentacje i zespoły z Azji oraz stowarzyszenia/uczestników rozgrywek azjatyckich. To nie jest oficjalna lista FIFA/AFC; zakres jest szeroki i obejmuje m.in. Guam, Makau, Mariany Północne i Chińskie Tajpej.
